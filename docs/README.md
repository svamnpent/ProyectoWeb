# 📄 Centro de Documentación - Proyecto General

Este directorio está destinado exclusivamente a la gestión, almacenamiento y control de versiones de toda la documentación formal relacionada con el desarrollo del proyecto de la asignatura **Desarrollo Web Integrado (31595)**.

---

## 📌 Reglas de Organización

Para mantener el orden y evitar que el repositorio se sature con archivos temporales, sigue estas normas:

- **Formatos Permitidos:** Sube preferentemente archivos en formato **PDF** para documentos finales, imágenes corporativas/diagramas en **PNG/JPG**, o archivos de texto en **Markdown (.md)**.
- **Prohibido:** No se deben subir borradores desorganizados, instaladores o archivos de código fuente en esta carpeta.
- **Nombres de Archivos:** Usa nombres claros en minúsculas, separados por guiones (ejemplo: `manual-usuario.pdf`, `diagrama-entidad-relacion.png`).

---

## 📂 Estructura de Documentos

Se organizara los archivos dentro de esta carpeta utilizando la siguiente estructura de subdirectorios, estos (documento son de ejemplo):

```text
docs/
├── README.md                 # Este índice de documentación
├── 01_planificacion/         # Acta de constitución, cronograma y requerimientos
├── 02_diseño/                # Wireframes, prototipos de UI/UX y paleta de colores
├── 03_arquitectura/          # Diagramas de bases de datos (DER), arquitectura y diagramas de clases
└── 04_manuales/              # Manual de usuario y manual de despliegue/instalación
```
