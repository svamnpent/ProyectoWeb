# 🧪 Laboratorio 1 - Introducción a Spring Boot, Maven y Java 25

Este directorio está dedicado al desarrollo de la primera sesión práctica del curso **Desarrollo Web Integrado (31595)**. En esta práctica sentamos las bases del desarrollo backend utilizando el ecosistema moderno de Java.

---

## 🎯 Objetivo de la Sesión

Al finalizar esta práctica, el estudiante será capaz de:

- **Crear, ejecutar y empaqueta** un proyecto **Spring Boot** básico gestionado con **Maven** y utilizando **Java 25**.
- **Identificar la estructura principal** de un proyecto Spring Boot y entender la función de cada uno de sus directorios.
- **Comprender el flujo de arranque** y ciclo de vida inicial de la aplicación.
- **Reconocer el rol inicial de los controladores REST** (`@RestController`) para la exposición de endpoints en una aplicación web backend.

---

## ⚙️ Tecnologías Utilizadas

- **Lenguaje:** Java 25
- **Framework:** Spring Boot 3.x (o versión indicada en clase)
- **Gestor de Dependencias:** Apache Maven
- **Arquitectura:** REST API (Controladores Iniciales)

## 📝 Guía de Entregas y Pasos a Seguir

1. **Creación del Proyecto:** Utiliza [Spring Initializr](https://spring.io) o tu IDE preferido para generar el proyecto con Maven y Java 25.
2. **Desarrollo:** Implementa el código base y tu primer controlador REST según las indicaciones de la guía de la clase.
3. **Validación:** Asegúrate de que la aplicación compile sin errores mediante `./mvnw clean install` y corra localmente.
4. **Subida al Repositorio:** Guarda tus archivos dentro de tu respectiva carpeta personal. No alteres el trabajo de tus compañeros.
